How to use SQL queries

Этот dashboard показывает SQL-файлы, а выполнять их нужно в Oracle SQL Developer, SQL*Plus или APEX SQL Workshop.
Открой Oracle SQL Developer
Подключись к своей Oracle database schema.
Запусти reset при необходимости
Если таблицы уже были созданы раньше, сначала выполни database/00_drop.sql.
Запусти scripts по порядку
Schema → package spec → package body → seed data → sample queries.
Покажи результат в UI
На защите можно открыть эту страницу и SQL-файлы, а затем выполнить запросы в Oracle.
@database/00_drop.sql
@database/01_schema.sql
@database/02_package_spec.sql
@database/03_package_body.sql
@database/04_seed.sql
@database/05_sample_queries.sql
Если используешь SQL Developer, открой каждый .sql файл и нажми Run Script. Если используешь SQL*Plus, команды выше запускаются из папки проекта.

Database Functionalities

Covered in PL/SQL
Authentication
authenticate_user checks role, email, password and active status.
Product management
add_product and update_product_stock validate seller ownership and stock rules.
Feedback flow
submit_feedback, reply_feedback, delete_feedback enforce buyer/seller/admin rules.
Notifications
Triggers and procedures notify seller/buyer about changes.
Audit history
Feedback insert/update/delete operations are written into audit log.
Analytics
Dashboard stats, average rating, pending replies, unread notifications and low-stock products.
